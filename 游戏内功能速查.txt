【物品栏 / 装备（AzuEPI 扩展物品栏）】
  Alt + 左键 点物品        收藏这个物品（金色边框）—— 不会被一键入库 / 自动整理搬走
  Alt + 右键 点背包格子    收藏这个格子（蓝色边框）—— 放进该格的任何东西都受保护
  两者叠加（收藏的物品在收藏的格子里）边框变绿
  再点一次同样的操作       取消收藏
  快捷栏（当前启用 3 个）：按住左 Alt 再按 Z / X / C（AzuEPI 的 [8 - Quick Slot Hotkeys]）
      · 必须“按住 Alt 再按”，单按 Z/X/C 无效；那 3 格里要放东西才会有效果
      · 前提：背包/地图/商店等界面处于关闭状态（开着界面时快捷键不生效）
      · ⚠ 注意冲突：DodgeShortcut 把“左 Alt”设成了翻滚键，所以按 Alt 会同时翻滚一次。
        想干净地用快捷栏，建议把翻滚键改成鼠标侧键：F1 → DodgeShortcut → DodgeShortcut = Mouse3（或 Mouse4）
  装备面板按钮            物品栏顶部的虚荣(Vanity)/配装(Loadout)按钮；配装面板里
                          左键=装备，右键(或 Ctrl+左键)=从配装里取出该物品
  属性面板                物品栏里的 📋 / 悬停角色名，可看 40+ 项实时属性

【储物 / 整理】
  背包格下方"整理"按钮       自研 InventorySortOnly：只整理 AzuEPI 的常规行，
                          第 1 行热键栏不动、收藏格不动、装备行不动
  P 键                     自研 SafeQuickStack：把背包里能并进附近箱子的物品快速存进去
                          （P2P 安全：不抢占箱子所有权；可连续处理多个物品）
  （本版禁用）ChestFlow     共享箱子/自动喂动物/自动补货/储物规则这一套本版【已禁用】，
                          相关快捷键（Alt+S 整理箱子、Alt+左键 锁定/补货循环）都不生效；
                          真的需要可在 r2modman 里自行启用（注意：多人同开一箱有丢物风险）。
  （提示）ChestFlow 本版不随包/已禁用；它的快速存取由自研 SafeQuickStack（P 键）替代。

【耐力技能（blacks7ar-Endurance 1.1.2，本地简体汉化）】
================================================================
  技能列表里叫 Endurance（技能名保留英文，因为它是技能的内部标识）
  怎么练：消耗耐力会累积，累计超过 25 点涨一次技能经验（每次涨幅 ≈ 消耗量 / 最大耐力）
  收益（技能等级/100 × 系数）：
      最大耐力  100 级时 +75
      耐力回复  基础 5 → 100 级 15
  死亡默认不掉这个技能的经验
  参数在 F1 → Endurance（Stamina Factor / StaminaRegen Factor / Stamina Threshold / 显示提示 / 经验倍率 / 死亡损失）

【传送门：为什么“有时不能传”】
================================================================
  先看游戏提示的是哪一句，一一对应：
  1) 「有物品阻止你进入传送门」
     → 身上带着“不可传送物品”（矿石、金属锭：铜/锡/青铜/铁/银/黑金属/炎铁…）。清掉再传。
  2) 「被邪恶力量阻挡了。」
     → 世界开了「没有boss传送（No boss portals）」修饰符，且此刻有 boss 活着/在战斗中。
       注意：**“硬核（Hardcore）”世界预设自带这条**。boss 死后即可正常传送。
       服务端（房主）可用控制台关掉：removekey NoBossPortals（listkeys 可查当前是否开着）
  3) 「被挡住」
     → 两种可能：① 目标区块还没加载好（等 1~2 秒再按一次，尤其人多/服务器卡时）
                 ② 世界开了「无传送门（No portals）」，所有传送门都不工作
  4) 另外：传送本身有 2 秒冷却，动画没走完再点也不会开始。

【传送门位置不显示给队友（PortalBroadcastFix 1.0.0，自制／装在服务端）】
================================================================
  症状：你放了一扇新传送门（模式=Public），远处的队友在传送门选择地图上完全看不到它，
        要等他重连、或服务器重启一下才出现。
  原因：TargetPortal 靠“服务端把新出现的门广播给所有客户端”来分享门的坐标，但它内部算差集的
        集合被自己漏掉了一步，导致新门永远不广播；原版又只把传送门数据发给附近的人。
        （上游 issue #79 就是这个，作者未修）
  修法：本档内置自制补丁重做这次广播（服务端侧）：
        · 每 5 秒发现“新出现的传送门” → 立刻广播给所有客户端
        · 有人刚进服 → 下一跳把全部传送门重推一遍
        · 兜底每 2 分钟全量重推一次（原版会跳过已经是最新的，开销可忽略）
  · 生效条件：**必须放在服务端（房主那台）的 BepInEx\plugins\PortalBroadcastFix 目录**；
              客户端装不装都行（装了不会做任何事，也没有副作用）
  · F5 控制台：pbfix_status 看状态；pbfix_now 立刻全量重推一次
  · 日志（服务端）会写：广播 N 个传送门 ZDO 给所有客户端
  · 想关掉：删掉服务器的 BepInEx\plugins\PortalBroadcastFix 目录，或 F1 里关它的 Enabled

【旧版 ValheimVRM / VRMGhostFix】
================================================================
  ValheimVRM 1.2.2 的已知 bug：传送到另一个传送门时会多出一个自己的人物模型，再传一次才消失。
  本档内置自制补丁修好了：传完自动清理残留模型（日志里会写一行“清理幽灵模型 …”）。
  · 换了 ValheimVRM 版本或点了它的 Reinstall，这个补丁可能失效（日志会提示“没找到 ValheimVRM 的类型”）
  · 想关掉：删掉 BepInEx\plugins\VRMGhostFix 目录即可

【2026-09-15 新增：随身保险柜 / 死亡保留 buff / 钓鱼】

随身保险柜（SafeBox，装备栏下方 3x3 面板）
  · 左键点柜内物品 = 拿起 → 点背包或柜内任意格 = 放下（柜内格子可随意摆放，占用自动对调）
  · 从背包拖到柜内指定格 = 存进那一格
  · Shift+左键 = 原版分拆对话框（拆分一半/任意数量）
  · 右键 = 使用/装备（箱子同款语义）
  · Ctrl+左键（LeftAlt 同效）= 快速存取：没开箱子 = 背包⇄保险柜；开着箱子 = 背包⇄箱子
  · 捡到的东西若柜里已有同类未满堆 → 自动并进柜里；柜里没有的进背包（你手动取出的不会被吸回）
  · 柜内物品死亡不掉落、复活仍在；自动落盘到 BepInEx\config\SafeBox\<玩家ID>_<角色名>.box
  · F5 控制台：safebox list / take <序号> / take all / ui / reload / help

死亡保留 buff（KeepBuffsOnDeath）
  · 死亡时把正面状态效果（Rested 等，含剩余时间/等级）快照，复活后原样恢复；负面效果一律不带
  · 配置：local.zuiaiyan.keepbuffsondeath.cfg（可关、可调最小剩余时间）

钓鱼（Hooked）
  · 咬钩后出现浮标条：按住格挡抬条、松手落条，让鱼留在绿条里把右侧进度打满即上钩
  · 完美上钩（鱼没跑出条）额外给技能与品质；鱼饵各有加成（热鱼饵 25% 双鱼等）
  · 本包已收敛收益：宝箱 5%、只抽 1 次、关掉 +50 负重 buff；护栏（不进矿石/只出已知物品）保持开启
  · 想回官方默认：改 Azumatt.Hooked.cfg 的 Fresh Catch→On、Treasure Chance→0.15、Rolls Max→2
