英灵神殿 MAKABAKA 整合档 —— 2026-09-17 更新说明（v1.5）
（上一版：v1.4 / 2026-09-17）

【本版重点：新增「武器/物品外观替换」独立模块】—— 弓的模型替换不再是写死的一把弓
  · 一键安装里多了一步：先选「要换哪件东西」，再选「用哪个模型」，也可以选「不替换」
      - 可选目标 50 个（弓/剑/刀/斧/锤/长柄斧/矛/战斧/大锤/盾/镐/工具…），都是游戏里真实存在的物品；
        也可以直接输入任意 prefab 名（清单文件 Models\武器替换\目标清单.txt 可自行增删）
      - 模型来自 Models\武器替换\<模型名>\（*.obj + textures\*.png + 可选 模型.json）：
        往里丢一个新文件夹，菜单就会自动多一个选项，不用改脚本、不用重新编译
      - 不替换 = 保持原版外观（插件保留但 Enabled=false）
  · 模型不再塞进插件本体：插件是通用的「物品外观替换器」（BepInEx\plugins\ItemSkin\），
    目标物品与模型都由配置决定，游戏里按 F1 可微调（缩放/旋转/平移/光泽/金属度/发光颜色）
  · 沿用原来的做法：网格走 OBJ、贴图走 PNG，运行时构建 → 不依赖 AssetBundle（游戏 Unity 6 vs 本地编辑器 2023.1）
  · 适用：静态网格物品（武器/工具/盾）；带骨骼的盔甲/玩家部件不适用
  · 纯客户端外观：不改数值、不发网络包、不写存档；别人没装就还是原版外观
  · 参数：-SkinTarget <prefab> -SkinModel <模型目录名>（一起给才生效）、-SkipSkin 跳过本模块
  · 原来的 BowSkinLingyue 插件已被取代（档案里改名为 _旧_BowSkinLingyue_已迁移），
    默认目标仍是 尸鬼之牙 ← 灵跃心弦，观感与之前一致

英灵神殿 MAKABAKA 整合档 —— 2026-09-17 更新说明（v1.4，历史）
（上一版：v1.3 / 2026-09-16，安装包 138.0 MB）

【本版重点：安装包瘦身 —— 角色模型改为「按需下载」】
  · 角色模型【不再打进安装包】，也不再放进仓库：安装包只含 mod 本体 + 脚本 + 文档
      - 只更新 mod 的人：安装包 138.0 MB → 82.3 MB；git 方式 clone 从 450+ MB → 约 0.6 MB
      - 想装/换模型的人：安装时或双击「换模型.bat」时再选（可多选，如 1,3 或 2-4）；
        下过的模型存在本机，以后切换是秒级、不重下
  · 模型来源：私有仓库的 Release 附件（不进公开仓库，避免二次配布问题）；
    脚本按包内 Models\models.json 清单下载，并校验 sha256（清单 13 个模型，zip 后每个 13–77 MB）
  · 首次下载模型需要一次「只读令牌」：脚本会问一次并记住（存到 模型凭据.txt）；
    也可设环境变量 MAKABAKA_MODEL_TOKEN，或用 -ModelToken 传参；
    不想用令牌也行：把 .vrm 直接拖进来，用 -ModelPath 指过去
  · 新增参数：
      -ModsOnly              只更新 mod（日常升级用这个，完全不碰模型）
      -ListModels            只列出可选模型（已缓存 / 需下载 + 大小）后退出，不动任何文件
      -Models "金乌-毛绒派对,辰星-琼弦 慵倚花阴"   预选要下载并缓存的模型
      -ModelPath <文件|目录> 用本地的 .vrm
  · 本版模型清单调整：新增「辰星-琼弦 慵倚花阴」(36.5 MB)；「安卡希雅-叶荫闲趣」只保留权重裙版（物理裙版下线）
  · 新增每个模型的参考图：包内 Models\预览\（13 张 450×700 JPEG＋一张带编号总览图，约 0.5 MB，编号 = 选择菜单里的序号）
  · 选模型时可以直接看图：菜单里输 p = 打开总览图（一张看全部）+ p3 = 看第 3 个的大图 + f = 打开参考图文件夹；
    看完自动回到菜单，不用退出去翻文件夹
  · 【取消默认模型】不再把某个模型排到第一位：菜单顺序 = 清单顺序 = 参考图编号（1 太一·庚辰 … 12 辰星 … 13 金乌）；
    选模型请按编号挑，直接回车 = 不换（保持现状），不会再默默替你选一个
  · 【联机稳定性】新增《联机一致性自检.bat》—— 进服前每人跑一次，房主用 -Compare 比对
    mod 版本 / 插件 DLL（MD5）/ 关键配置，防止“同一箱子两人看到的不一样、物品回滚”
  · 联机数据同步隐患排查报告见包内「联机数据同步排查_20260917.md」（含高风险项与固定动作）
  · 【默认关闭】ChestFlow「多人同时开同一个箱子」→ AllowConcurrentChestUse=false
    （ChestFlow 自带默认是 true；这一项不看房主配置，所以安装脚本会在装完后强制校正，升级保留 config 也兜得住）
  · 细节见包内「模型说明.txt」

【修复】
  · 新放的传送门，队友不重连也能立刻看到（新增自制插件 PortalBroadcastFix 1.0.0）
      - 之前：你放一扇新门（模式 Public），远处队友的"传送门选择地图"上完全看不到，
        要等他重连、或服务器重启一次才出现。
      - 原因：TargetPortal 1.2.6 用来判断"新门"的那个集合被它自己的 Awake 钩子提前污染，
        新门永远不会被广播；原版又只把传送门数据发给附近区段的人。
        （上游 issue #79 就是这个，作者未修，也没有更新的版本可升）
      - 现在：服务端每 5 秒发现新门就广播给所有人；有人刚进服下一跳全量重推；
        每 2 分钟兜底全量重推一次。
      - ⚠ 记得装到服务端：BepInEx\plugins\PortalBroadcastFix\PortalBroadcastFix.dll
        （客户端装了不做任何事，也没有副作用）
      - 想关掉：删掉服务器的该插件目录，或 F1 里关 Enabled

【安装方式】
  · 方式一（推荐，最省流量）：先 clone 仓库（0.6 MB），以后每次只 git pull；
    再跑 install.ps1 或双击 一键安装.bat（升级时加 -ModsOnly 就只更 mod）
  · 方式二：直接从 Releases 下 MAKABAKA_profile_v1.4_20260917.zip（82.3 MB）解压安装
  · ⚠ 老版本 clone 过仓库的朋友：本版重写过历史（把模型从 git 里移走了），
    请执行一次  git fetch origin && git reset --hard origin/main
    （或干脆删掉重新 clone，反正只有 0.6 MB）
