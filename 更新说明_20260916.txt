英灵神殿 MAKABAKA 整合档 —— 2026-09-16 更新说明（v1.1）
（上一版：v1.0 / 2026-09-15）

【本版重点：一键安装体验 + ValheimVRM（角色换模型）流程】
  · mod 内容与 v1.0 相同（Thunderstore 42 包 37 启用 / 5 禁用 + 3 个自制插件），
    本版升级的是"安装脚本"和"角色模型"这两块，老玩家直接重跑一次安装即可。

【角色模型：现在可以在脚本里挑、自己输角色名】
  · 安装时会列出可选模型：
        1) 金乌（59.8 MB）   ← 默认
        2) 辰星（36.7 MB）
        0) 不换模型（保持现状）
  · 接着问【你的角色名】—— 填你在游戏里的角色名即可（每个人不一样）。
    脚本会把模型复制成  <游戏>\ValheimVRM\<角色名>.vrm
    并把设置复制成      <游戏>\ValheimVRM\settings_<角色名>.txt
    → 你不需要去文件夹里找文件、也不需要手动改名。
  · 目录里已有以前用过的模型名时会列出来，直接输编号选用（省事又不会拼错）。
  · 旧模型默认留着；也可以选择一键收进  <游戏>\ValheimVRM\_旧模型_<时间>\ 备份。
  · 文件名规则（照插件源码确认）：必须叫 <角色名>.vrm 与 settings_<角色名>.txt，
    拼写要和游戏里一致（大小写无所谓，字母不能错）。改完必须完全重启游戏。

【新增：换模型.bat（只换模型，不重装整个档）】
  · 想换模型或改角色名：双击包里的「换模型.bat」，选模型 + 输角色名即可
    （不用再下 100MB 的安装包；在线安装过的机器会把模型缓存到本机，
      之后换模型连下载都免了）
  · 命令行等价写法： powershell -File install.ps1 -VRMOnly
    或直接指定： -VRMOnly -VrmModel 辰星 -CharName 你的角色名 -NonInteractive

【ValheimVRM 安装方式升级：两处落点都自动做好】
  · 这个 mod 与别的不一样，文件要落两个地方，r2modman 只管其中一个：
        ① 插件（ValheimVRM.dll + .shaders） → r2modman 的档里 BepInEx\plugins\ValheimVRM_1.2.2\
        ② 运行时 dll（15 个）                → 游戏本体 valheim_Data\Managed\
        ③ 模型与设置                          → 游戏本体 ValheimVRM\
  · 每个文件都比对 MD5：缺的补上、内容不一样的换成一致的（替换前自动备份）。
    插件那半会先找档里已有的位置就地修复，不会新建平行目录（避免插件重复加载）。
  · 装完打印「VRM 三处自检」，三行都应是 [✓]：
        [✓] ① 插件（档里）   [✓] ② Managed dll（游戏里）   [✓] ③ 模型（游戏里）
  · 找不到游戏目录也不影响 ①（插件那半照装），之后重跑脚本补 ②③ 即可。

【其它改进】
  · 新增「安装步骤.txt」：一份可以直接转发给别人的完整安装步骤
    （准备 → 三种装法：一行命令 / git clone + 双击 / 手动下 Release 附件 → 进游戏 → 联机 → 排查）
  · 升级备份更耐错：目标档缺 mods.yml（半装坏的档）不再中断安装，只备份 plugins 目录并提示
  · 包内容去个人化：不再包含按玩家 SteamID 的状态文件，也不含任何个人角色名
  · 安装包布局调整：模型从旧的 ValheimVRM.zip 改为 Models\金乌\、Models\辰星\
    （旧布局仍兼容：老脚本继续能用包内的 ValheimVRM_1.2.2.zip 手动安装）

【老玩家怎么更新】
  · 一行命令 / 手动下载装的：重跑一次即可（每次取最新版）
  · git 装的： git pull  → 再双击一次「一键安装.bat」
  · 只想换模型 / 改角色名：双击「换模型.bat」（新版包才有这个文件）
