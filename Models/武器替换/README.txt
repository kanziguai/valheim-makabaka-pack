武器/物品外观替换 —— 模型库
=================================================
结构：
  本目录/                 目标清单.txt（可选目标）+ models.json（模型下载清单：从私有仓库按需取）
  本目录/<模型名>/         模型实体：*.obj + textures\*.png + 模型.json（本地自用，不进公开包）

许可口径（重要）：
  · 这些模型是改造过的同人/扒出资源 —— **仅供本地自用，禁二次配布/拆件/商用**。
  · 所以模型实体**不进公开安装包、不进公开仓库**，只放在私有仓库的 Release 附件里；
    安装脚本用「模型凭据.txt」里的令牌下载并校验 sha256（和角色模型同一套机制）。

加新模型（本地自用）：
  1) 把模型文件夹丢进本目录：<名>/xxx.obj + <名>/textures/*.png（可选 <名>/模型.json 精确指定
     贴图槽位 slots[]、缩放 scale、旋转 rotationEuler、平移 offset、发光槽位 glowSlot/glowTintHex）
  2) 想分发给持令牌的朋友：打包成 ASCII 名的 zip 传到私有仓库 Release（models-v1），
     并在 models.json 里登记 name/dir/asset/zipSize/sha256/defTarget。
一键安装的「武器/物品外观替换」模块会自动读到：本地有的直接用，只有清单里的自动下载。
