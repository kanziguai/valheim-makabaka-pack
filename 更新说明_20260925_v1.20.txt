MAKABAKA v1.20（2026-09-25）

本版 = v1.19 的全部内容 + 新增自研插件 RecycleYieldTweak + 武器外观替换清单改为"只列弓" + 文档修正。

【新】自研 RecycleYieldTweak 1.0.0：附魔装备回收的材料固定给
- 背景：Recycle_N_Reclaim 原本按"稀有度 + 物品类型"去 EpicLoot 配置里查附魔成本，还要逐条校验
  "你认不认识这件附魔材料 / 有没有学会它的配方"，任何一步不满足就静默跳过（或者加个"缺少需求"把整件挡住）→
  表现就是"有的附魔装备拆了给尘/精华，有的什么也不给"，而且日志里看不到原因。
- 现在：只要这件带附魔的装备本身能被回收 →
    · 基础材料：照旧（配方材料 × 50%；武器/护甲这类不可堆叠物品取整后至少各 1 个）
    · 附魔材料：固定给【对应稀有度的尘 ×2 + 精华 ×2】（饰品再 +1 符文石；非饰品 0）
    · 宝石（Jewelcrafting）照旧返还
    · 仍然必须在"做它的那个工作台 + 等级"旁边拆
- 参数（BepInEx\config\local.recycleyieldtweak.cfg，改完重启游戏即生效）：
    尘数量 = 2    精华数量 = 2    符文石数量(饰品) = 1    符文石数量(非饰品) = 0
    算饰品的物品类型 = Trinket;Utility        详细日志 = true
- 它不动 Recycle_N_Reclaim.dll 一个字节（用 Harmony 前置补丁接管那一步）→ 那个 mod 的版本校验/哈希校验不受影响；
  不想要就删 BepInEx\plugins\RecycleYieldTweak\ 整个文件夹即回退。
- 回收是客户端行为：谁装了这个插件，谁回收时按新规则拿材料（本包已带，大家一致）。

【改】武器/物品外观替换：目标清单只列弓
- 以前清单里混着弓/剑/斧/盾/镐/工具…共 50 项，而弓只列了 4 支（游戏里其实有 12 支）。
- 现在清单只列【12 支弓】：粗弓 / 细木弓 / 猎户弓 / 尸鬼之牙 / 断脊 / 灰烬之牙 / 嗜血之牙 / 邪根之牙 /
  风暴之牙 / 北境之弓 / 雷血之弓 / 冰火之弓（prefab 名与显示名都对着游戏数据逐个核对过）。
  弩、剑、斧、盾、法杖等其它物品不再列出（需要时仍可在安装时直接手输 prefab 名）。
- 顺带纠正旧清单里几个显示名（例："猎人之弓" → 官方名「猎户弓」）。
- SkinLib.ps1 同步：补上 弩/双手剑/戟/法杖/拳套/工具 的类型识别，且弓和弩算一家（选了弓类模型时弩也排前面）。
- 模型库本身没变（仍是 灵跃心弦 / 昔涟弓 两只弓模型）。

【修】一键安装：外观替换的"交互选择"会当场报错中断（本版实测发现，已修）
- 现象：跑到「武器/物品外观替换」这一步，选完模型（第 1 步）和目标物品（第 2 步）后立刻红字报错并中断：
    Cannot convert value "System.Management.Automation.PSCustomObject" to type
    "System.Management.Automation.SwitchParameter"...
- 原因：脚本参数里有个 [switch]$Pick，而外观那段的局部变量叫 $pick —— PowerShell 变量名不区分大小写，
  给 [switch] 变量赋一个 PSCustomObject 会直接抛这个异常（复现与修复都已在真机 PowerShell 上验过）。
- 修法：那个局部变量改名 $pick → $skinSel（行为不变）。本版包内 install.ps1 已修。
- 已经跑到一半中断的：重跑一次一键安装即可（前面几步不会重复装；外观这一步选 1→想要的弓即可）。
