命名规则（从 v1.0 起）：安装包文件名一律带版本号，格式
  MAKABAKA_profile_v<主.次>_<打包日期>.zip
  升级包 → 版本号递增（v1.1、v1.2…），日期为打包当天。
安装脚本会自动识别任意版本的包名，并在 [1/7] 那一步打印"包版本：vX.Y"。

v1.2 含：Valheim 1.0 联机档 MAKABAKA —— Thunderstore 42 包（37 启用 / 5 禁用）
  + 自制插件 3 个（SafeBox 0.5.4、KeepBuffsOnDeath 1.0.1、ChestFlow 及界面汉化）
  + Azumatt-Hooked 1.1.1（已按平衡设置调好）
  + RobgobStuff-Achievement_Enabler_Plus 2.0.3（清作弊标记 + 恢复成就）

v1.2 新增/改动：
  · 下载时实时显示【百分比 / 已下 MB / 当前速度 / 剩余时间】，完成给一行汇总（总大小/用时/平均速度）
    —— 旧版用的是 WebClient 同步下载，它不触发进度事件，所以以前看不到进度和速度
  · 下载完整性校验：收到的字节数与应有大小不一致就判失败、自动换线路重试（防截断包）
  · 安装包下载/解压位置可选：首次运行会问一次（默认 %TEMP%\makabaka_pack，可换到别的盘，
    比如 D:\MAKABAKA_install），选完记住；也可用参数 -DownloadDir 指定。
    换模型用的模型缓存（约 100MB）会跟着放到你选的目录里的 VRM_Models\ 下
  · 多个 r2modman 数据文件夹时会列出来让你选（有人每块盘都装过一份）：标出哪个"已有 MAKABAKA 档"、
    哪个是"上次装在这"；直接回车 = 第 1 项，输 9 = 再扫描所有硬盘，输 0 = 自己输入路径。
    只有一个数据文件夹时不会问
  · README / 安装步骤.txt 里的"git 装法"改成一段命令（自动 clone 或 pull 后直接开始安装，
    不用手动 cd 进目录、不用去双击 bat）
